# How to Use Revizto UI Kit in Lovable.dev

## 📋 Step-by-Step Setup

### Step 1: Add UI Kit to Your Project

1. **Create a new file** in Lovable.dev
   - Click "Add file" or "+"
   - Name it: `revizto-ui-tailwind.jsx`

2. **Copy the component library**
   - Open `revizto-ui-tailwind.jsx` from this repository
   - Copy ALL content
   - Paste into your new file in Lovable

3. **Save the file**
   - The file should appear in your project sidebar

### Step 2: Configure Lovable AI with Instructions

Lovable.dev has a **Project Instructions** feature where you can add custom rules for the AI.

#### Option A: Full Instructions (Recommended)

1. In Lovable, click **Settings** or **Project Settings**
2. Look for **"Custom Instructions"** or **"AI Instructions"** section
3. Copy content from `LOVABLE_INSTRUCTIONS.md`
4. Paste into the instructions field
5. Save

#### Option B: Short Instructions (Quick Setup)

1. In Lovable, find the **Instructions** or **Prompt** field
2. Copy content from `LOVABLE_PROMPT_SHORT.txt`
3. Paste it
4. Save

### Step 3: Test the Setup

Create a test component to verify everything works:

```jsx
// Create new file: TestComponent.jsx

import { Button, Input, Modal } from './revizto-ui-tailwind';
import { useState } from 'react';

export default function TestComponent() {
  const [name, setName] = useState('');
  const [isOpen, setIsOpen] = useState(false);

  return (
    <div className="p-8 space-y-4">
      <h1 className="text-2xl font-bold">Revizto UI Kit Test</h1>
      
      <Input
        placeholder="Enter your name"
        value={name}
        onChange={(e) => setName(e.target.value)}
      />
      
      <Button variant="primary" onClick={() => setIsOpen(true)}>
        Open Modal
      </Button>

      <Modal
        isOpen={isOpen}
        onClose={() => setIsOpen(false)}
        title="Hello!"
      >
        <p>Your name is: {name || 'Not entered yet'}</p>
      </Modal>
    </div>
  );
}
```

### Step 4: Start Building

Now you can tell Lovable AI what to build:

**Example prompts:**
- "Create a login form with email and password"
- "Add a settings page with toggles for notifications"
- "Build a search interface with filters"
- "Create a task list with status indicators"

The AI will use ONLY Revizto components!

## 💡 Tips for Working with Lovable AI

### 1. Be Specific About Components

**Good prompts:**
```
"Create a form with Input fields and a primary Button"
"Add a Modal with a warning Alert inside"
"Build a search bar using SearchField component"
```

**Vague prompts (may cause issues):**
```
"Make it look nice" 
"Add some buttons"
"Create inputs"
```

### 2. Reference Component Names

Always mention Revizto component names:
```
"Use the Dropdown component for category selection"
"Add a Toggle for the enable/disable option"
"Show status with the Status component"
```

### 3. Remind AI if Needed

If AI forgets and creates custom components, say:
```
"Use only Revizto UI Kit components from revizto-ui-tailwind.jsx"
"Please use the Button component, not a custom button"
```

### 4. Request Specific Variants

```
"Use primary Button variant for submit"
"Use outline Button variant for cancel"
"Show an error Alert variant"
```

## 🐛 Troubleshooting

### Problem: AI Creates Custom Components

**Solution:**
1. Remind AI: "Use only Revizto components"
2. Check if instructions are saved in settings
3. Re-paste the short prompt in chat

### Problem: Import Errors

**Check:**
- File name is exactly: `revizto-ui-tailwind.jsx`
- Import path is: `'./revizto-ui-tailwind'`
- File is in the same directory

**Fix:**
```jsx
// If file is in /components folder:
import { Button } from '../revizto-ui-tailwind';

// If file is in root:
import { Button } from './revizto-ui-tailwind';
```

### Problem: Components Look Wrong

**Check:**
- Tailwind CSS is enabled (it should be by default in Lovable)
- No conflicting CSS in your project
- Using correct prop names

### Problem: Props Not Working

**Verify:**
- Prop name matches documentation exactly
- Value type is correct (string, boolean, number)
- Component supports that prop

**Example:**
```jsx
// ❌ Wrong - 'color' doesn't exist
<Button color="blue">Click</Button>

// ✅ Correct - use 'variant'
<Button variant="primary">Click</Button>
```

## 🚀 Advanced Usage

### Combining with Tailwind

You can use Tailwind classes with Revizto components:

```jsx
<Button 
  variant="primary"
  className="w-full mt-4 shadow-lg"
>
  Full Width Button
</Button>

<Input
  placeholder="Email"
  className="max-w-md"
/>
```

### Creating Layouts

Use standard HTML/Tailwind for layout, Revizto for UI:

```jsx
<div className="grid grid-cols-2 gap-4">
  <div className="space-y-2">
    <Input placeholder="First Name" />
    <Input placeholder="Last Name" />
  </div>
  
  <div className="space-y-2">
    <Input placeholder="Email" />
    <Input placeholder="Phone" />
  </div>
</div>
```

### Composition Patterns

Build complex UIs by composing Revizto components:

```jsx
function SettingsPanel() {
  return (
    <div className="space-y-6">
      {/* Section 1 */}
      <div>
        <h3 className="font-semibold mb-3">Notifications</h3>
        <Toggle label="Email notifications" />
        <Toggle label="Push notifications" />
      </div>
      
      {/* Section 2 */}
      <div>
        <h3 className="font-semibold mb-3">Privacy</h3>
        <Checkbox label="Make profile public" />
        <Checkbox label="Show activity" />
      </div>
      
      {/* Actions */}
      <div className="flex gap-2">
        <Button variant="primary">Save</Button>
        <Button variant="ghost">Cancel</Button>
      </div>
    </div>
  );
}
```

```jsx

  <label className="text-sm font-medium">Email</label>
  <Input placeholder="Enter email" />

```

**Button Group:**
```jsx
<div className="flex gap-2">
  <Button variant="primary">Save</Button>
```

