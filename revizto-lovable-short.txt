MANDATORY RULES FOR THIS PROJECT:

1. ONLY use components from './revizto-ui-tailwind'
   ✅ import { Button, Input, Modal } from './revizto-ui-tailwind';
   ❌ NEVER use: <button>, <input>, <select>, or any raw HTML

2. AVAILABLE COMPONENTS:
   Button, Input, TextArea, SearchField, Dropdown, Modal, 
   Checkbox, RadioButton, Toggle, Slider, Tabs, Tooltip,
   Badge, Status, Alert, ListItem

3. ONLY use documented props:
   Button: variant, size, disabled, onClick, className
   Input: placeholder, value, onChange, disabled, error, className
   Modal: isOpen, onClose, title, footer, children
   (See LOVABLE_INSTRUCTIONS.md for full API)

4. FORBIDDEN ACTIONS:
   ❌ Creating custom UI components
   ❌ Using other UI libraries
   ❌ Modifying revizto-ui-tailwind.jsx
   ❌ Adding undocumented props
   ❌ Using raw HTML form elements

5. CUSTOMIZATION:
   ✅ Use className prop with Tailwind
   ✅ Wrap in layout divs
   ❌ DO NOT override component internals

EXAMPLE:
import { Button, Input } from './revizto-ui-tailwind';

function Form() {
  return (
    <div className="space-y-4">
      <Input placeholder="Name" />
      <Button variant="primary">Submit</Button>
    </div>
  );
}
